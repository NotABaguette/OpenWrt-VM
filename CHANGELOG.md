# Changelog

## 0.1.0

- Initial GitHub Actions workflow.
- Downloads the latest stable, snapshot, or exact OpenWrt x86_64 image.
- Verifies image SHA256 against OpenWrt `sha256sums`.
- Converts OpenWrt raw image to VMware streamOptimized VMDK.
- Generates OVF, OVA, ISO bundle, checksums, metadata, and GitHub Release.
